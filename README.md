## 📖 About Healix Advance Physiotherapy

**Healix Advance Physiotherapy and Rehabilitation Center** is an integrated clinical management and physical rehabilitation web application designed for multi-specialty physiotherapy centers. Located in **Sithalapakkam, Chennai**, Healix bridges the gap between clinical operations, patient home care dispatch, staff collaboration, and financial settlement through modern software engineering.

The platform combines an accessible patient-facing web experience with an executive medical director administration dashboard, a dedicated junior physiotherapist clinical station, and an enterprise **Java (JDK 21) Middleware Suite**.

---

## 🌟 Clinical Rehabilitation Specializations

Healix caters to patients of all ages recovering from acute physical trauma, surgeries, repetitive strain, and degenerative musculoskeletal disorders:

1. **🏃 Sports Injury Rehabilitation**
   - Targeted recovery protocols for ACL/PCL ligament tears, meniscus injuries, ankle sprains, rotator cuff strains, and tennis elbow.
   - Sports-specific mobility routines, kinetic chain re-education, and return-to-sport testing.

2. **🦴 Orthopedic Physiotherapy**
   - Non-surgical and conservative management of cervical spondylosis, lumbar disc herniation, sciatica, and osteoarthritis.
   - Posture correction, ergonomic assessment, and deep tissue mobilizations.

3. **🧠 Neurological Rehabilitation**
   - Evidence-based neuromuscular re-education for stroke recovery (hemiplegia), Parkinson’s disease, peripheral neuropathy, and spinal cord injuries.
   - Balance training, gait re-training, and fall-prevention exercises.

4. **🩺 Post-Surgical Joint Mobilization**
   - Early-phase and late-phase rehabilitation following Total Knee Replacement (TKR), Total Hip Replacement (THR), and spinal fusions.
   - Passive/active assisted range of motion (ROM), swelling control, and scar tissue mobilization.

5. **🏡 Doorstep Home Visit Physiotherapy**
   - Dedicated physical therapy delivered at the patient's residence for bedridden patients, elderly seniors, and acute post-operative cases.
   - Mobile electrotherapy (TENS/IFT), manual mobilization, and caregiver ergonomic training.

## 💻 Detailed Feature Breakdown

### 1. 🏠 Patient Self-Service Portal
- **Instant Consultation Scheduling**: Choose between in-clinic physiotherapy sessions or personalized home visits.
- **Doorstep Home Visit Dispatch**:
  - Enter exact home addresses and landmarks (e.g., *Near Ganapathipuram Water Tank*).
  - Pinpoint Google Maps GPS navigation link generation for visiting doctors.
  - Transparent home consultation fee (₹1500) with evening slots (05:00 PM – 07:00 PM).
- **Billing Ledger & Digital Payments**:
  - View itemized consultation invoices with `DUE` and `PAID` statuses.
  - Settle invoices online via simulated UPI (Google Pay, PhonePe, Paytm).
- **Official Downloadable Receipts**:
  - Printable, GST-compliant clinical receipts with security signatures (`HLX-SHA256-XXXX`) and verification barcodes.

### 2. 🩺 Junior Physiotherapist Clinical Portal
- **Daily Patient Queue**: View patients assigned for the current day's morning/evening rehabilitation shifts.
- **Clinical Charting & Progress Notes**: Record goniometer range of motion, muscle power grades, and electrotherapy notes.
- **Roster & Duty Shifts**: Verified access tied to doctor supervision under Dr. Calvin Joel.

### 3. 🛡️ Doctor & Executive Admin Cockpit
- **Chief Medical Officer Dashboard**: Unified view of today's patient visits, monthly income, active staff, and pending dues.
- **Financial Analytics & Revenue Charts**: Visual revenue trends, cash vs UPI distribution, and today's collections.
- **Patient Registry**: Complete digital health records, age, medical conditions, and full treatment histories.
- **Clinic Timetable Scheduler**:
  - 8 configurable hourly slots (09:00 AM to 07:00 PM).
  - Toggle slot availability (enable/disable for maintenance or holidays).
  - Monitor slot capacities and real-time booked session counters.
- **Staff Onboarding & Security Control**:
  - Onboard junior physiotherapists with defined shift timings.
  - Manage active/resigned staff status with immediate portal access revocation upon resignation.
- **Reception Desk Cash Collection**:
  - Collect payments directly at reception and issue authentic clinical receipts with cryptographically signed verification tokens.

## ☕ Java (JDK 21) Middleware Suite

To meet enterprise healthcare compliance and demonstrate full-stack polyglot architecture, Healix includes a complete **Java (JDK 21) Middleware Suite** located in [`server/src/middleware/java/`](server/src/middleware/java):

### Included Java Components:
1. **`HealixAuthFilter.java`**: Pure JDK 21 `com.sun.net.httpserver.Filter` enforcing RBAC for `ADMIN`, `NURSE`, and `PATIENT` endpoints.
2. **`HealixJakartaAuthFilter.java`**: Jakarta EE 10 / Servlet 6.0 filter compatible with Tomcat 10+ and WildFly.
3. **`HealixSpringAuthInterceptor.java`**: Spring Boot 3.x `HandlerInterceptor` with `@Component` annotations.
4. **`StandaloneMiddlewareDemo.java`**: Standalone HTTP test server with 11 automated test suites validating authentication headers, role restrictions, and audit logs.

### Running the Java Middleware Suite:
```powershell
# 1. Compile the Java classes
javac -d "server/src/middleware/java/bin" "server/src/middleware/java/*.java"

# 2. Run the automated RBAC verification test suite
java -cp "server/src/middleware/java/bin" middleware.StandaloneMiddlewareDemo
```

## 💻 Local Installation & Setup

Follow these steps to run the complete full-stack environment on your local machine:

### 1. Prerequisites
- **Node.js** (v18.x or v20.x+)
- **npm** (v9.x+)
- *(Optional)* **Java JDK 21** for running the Java middleware test suite

### 2. Clone the Repository
```bash
git clone https://github.com/Jobel26093/Healix---Website.git
cd Healix---Website
```

### 3. Install Dependencies
```bash
# Install frontend dependencies
cd client
npm install

# Install backend dependencies
cd ../server
npm install

# Return to root directory
cd ..
```

### 4. Run the Full-Stack Application
```bash
# Starts both Express API (Port 5000) and Vite React Client (Port 5173) concurrently
npm run dev
```

### 5. Access the Local Application
- 🌐 **Frontend Web App**: [http://localhost:5173](http://localhost:5173)
- ⚙️ **Backend REST API**: [http://localhost:5000/api](http://localhost:5000/api)
- 🏥 **API Health Check**: [http://localhost:5000/api/health](http://localhost:5000/api/health)
